## 一、总览与设计骨架

路线设计是一条**从「量产的残卷」走到「唯一的原典」**的渐进链：

```
空白的书页 ──记录附魔──> 《如我所书》      ← 战斗向毕业装
      │
      └─ 十诫残卷 ×10 + 圣典 ──> 补全十诫 ──> 圣典解绑
                                             │
                          安息仪式 ──────────┘
                             │（冥界 · 需击败过使徒 · 七件稀有素材）
                             ▼
                        启示试炼（四波）
                             │（通关 → 启示残卷 + 寂灭之星）
                             ▼
                        立约仪式（圣典 + 天启七印等）
                             ▼
                        圣约·原典（书籍栏 · 十诫路线的终点）
```

两条线的终点都是 book 槽，因此**互斥**（同槽只能戴一件）。

## 三、如我所书

**ID**：`yanscriptures:book_of_me`　**槽位**：book　**绑定**：戴上后只有创造模式能取下

### 3.1 基础属性（随记录附魔数量成长）

| 属性 | 数值 |
|---|---|
| 最大生命值 | 每个附魔 **+1** |
| 攻击力 | 每个附魔 **+1** |
| 幸运值 | 每个附魔 **+0.5** |
| 移动速度 | **+30%（独立乘区）** |

> 「已记录附魔恒定为 093」——**093 是崩铁致敬的设定值，不是强度门槛**。
> 收集数与属性脱钩，不要求玩家真去集齐 93 种附魔。

### 3.2 记录与回溯

- 按 **V** 记录当前状态（生命、饥饿、状态）
- 再次按 **V** 回溯，冷却 **180 秒**
- 状态记录消耗 10 种可用附魔

### 3.4 伤害相关的补充机制（战斗层）

- 攻击时若目标正在受玩家攻击，会叠加「灾厄印记」（由史诗饰品「灾厄」触发）
- 对戴书玩家的伤害拦截：负面效果在**施加阶段**即被拒绝（`MobEffectEvent.Applicable`）
- 免死：`LivingDeathEvent` 处有 **88%** 概率取消死亡并回满血
- 濒死保护：生命值掉到 0、但还没进入死亡动画时会被救回

### 3.5 毕业级免疫的硬边界（作者 2026-11-10 定，不要改）

《如我所书》与《圣约·原典》是**毕业饰品**，判定标准就是「**连 `/kill` 指令和虚空都杀不死**」。

- `genericKill`（`/kill` 与同类管理指令）：被**拦截**，提示「命运的力量挡下了虚空意志」。
- `fellOutOfWorld`（掉出世界/虚空）：先减免 66%，剩下一击致命时留 1 点血并取消。
- 死亡的最后一层（`LivingDeathEvent`）同样不对这两种伤害放行；血量被绕过事件层直接清零时，巡检层会拉回。
- **这条是刻意为之**，不是 bug：曾经为了「服务器里能收拾这个玩家」而放行过 `/kill` 与虚空，被作者否决并回退。

### 4.3 残卷

**10 张十诫残卷 + 1 张启示残卷**，均 `stacksTo(1)`。

**第八诫的判据**：只有从**野生的战利品容器**里取出物品才算「偷」；
玩家自己摆放的箱子、木桶、潜影盒、漏斗等一律不触发。
「是不是野生的」看容器里是否登记着战利品表——原生宝箱都算；别的模组自己实现、
不走原版宝箱那套的容器会被当成普通容器，也就是**不诅咒**（宁可漏判，不误伤玩家）。

稀有度：十张诫卷为**少见（黄色）**；**启示残卷**名字固定深红，与十诫残卷在物品栏里一眼可分。

**使用方式（十诫残卷）**：
- 必须佩戴《圣典·戒律》
- 对应诫条处于「已违逆」（有诅咒）且尚未补全
- 右键 → 补全该诫（写入 `Completed_n`、移除 `Curse_n`），消耗 1 张
- 补全后该诫**不再降罪**，祝福转为强化版

**启示残卷**：
- 普通：暗红色提示「等到那日子来临，举行盛大的仪式，这张残卷将揭示终结与新生。」
- 通过试炼（带 `TrialCleared:1b`）：亮白色「你已迈过了那审判，步入新天新地」

### 5.3 规则

| 项 | 设定 |
|---|---|
| 开场过渡 | **10 秒**（浮现第一段经文） |
| 波次间隔 | **30 秒**（超时不清场，必须清空当前波） |

| 生物破坏 | 试炼期间**关闭**，结束还原原值 |
| 敌人互伤 | 只禁止「试炼生物互相伤害」，**玩家召唤物照常生效** |
| 失败 | 玩家死亡/掉线 → 清场，**补回一张普通启示残卷** |

| 随机头衔 | 每只生成的 Boss 若带公开字段 `titleNumber`，随机分配 12 个头衔之一并立刻施加其效果（按字段名反射，不写死类名） |
| 等待超时 | 60 秒未见亚波伦则按已清空处理 |

### 5.4 奖励

通关后立即结算（不再等 30 秒间隔）：

- **启示残卷**（带 `TrialCleared:1b`）
- **寂灭之星 ×1**（原版仅 2.5% / 6.66% 凋灵掉落，故改为试炼保底）

### 6.4 界面与特效

- **特殊生命条**：左下角，带金属高光，颜色随比例变化（淡金 → 橙 → 红）
- **DPS 面板**：全局功能，任何玩家打怪都显示，5 秒窗口，附暴击统计
- **DPH 面板**：全局功能，左下角 DPS 面板上一层，显示**面板每击伤害**（把装备加成算完后的攻击力）、攻速与「每击 × 攻速」的预计 DPS；不打怪也能看到百分比加成有没有生效
- **罪孽层数条**：DPH 面板更上一层，只在佩戴《罪与罚》且层数 > 0 时出现，显示「罪孽 N / 10」，满 10 层转亮红

### 6.5 三段式介绍

| 操作 | 内容 |

### 6.6 大书页

**问题**：普通提示框一页只塞得下 5~12 行——十诫正文 30~50 行、圣约 12 条权柄 + 25 行典章、如我所书 30 多行，翻一次要滚十几次。

**做法**：鼠标悬停在物品上，**按一下 Shift+Alt** 打开整屏书页。

| 项 | 内容 |
|---|---|
| 尺寸 | 几乎占满屏幕（上下留 20 像素边距），一屏约 25~30 行 |
| 翻动 | 滚轮（3 行/格）、↑↓、PgUp/PgDn、Home/End；右侧有滚动条；Esc 关闭 |
| 折行 | 按宽度自动换行，颜色、粗体、斜体都保留 |
| 标题配色 | 标题与副标题**逐字渐变**，配色跟物品名一致：《圣约》金 → 暖白；《如我所书》天蓝 → 浅粉；《十诫》暗红 → 金；副标题统一暖灰 |
| 行距 | 正文行高 10；**段落间最多留一行空行**。标题在最上、副标题紧随其下，分隔线不压字 |
| 覆盖 | 《如我所书》（完整描述）、《圣约·原典》（权柄 + 典章明细）、《十诫》（强制展开触发条件与诅咒） |
| 不改动 | 旧的 tooltip 翻页逻辑全部保留（Shift 展开 + Shift+滚轮翻页），大书页只是多一个入口 |

**限制**：只在背包、饰品栏这类界面里生效（要鼠标停在物品上）；盯着地上掉的物品看不会触发。开书页不会拿走或移动物品。

### 6.7 与《如我所书》的关系

同为 `book` 槽，槽位容量 **4**，因此**可以同时佩戴**。两者互不覆盖，但注意：

- 几本会飞的书（《如我所书》《圣约·原典》《纯粹理性批判》、真我觉醒）走同一份「飞行许可」账：
  谁想飞就登记一份，全部撤回才真正关闭飞行；只要还有一本给飞行，摘掉另一本不会让你掉下来
- 《圣约·原典》的 F 键是**否决**：按掉之后即使同时戴着别的会飞的书也飞不了，再按一次恢复

**与《如我所书》同一档的硬边界**：两本都不吃 `/kill` 与虚空，判定标准见 §3.5（作者 2026-11-10 定，不要改）。

### 七·五·一、材料档位带来的加成

一条材料线记一档，一本书记三条线的档位，另记一项随机到的额外属性。

| 材料线 | Ⅰ | Ⅱ | Ⅲ | Ⅳ |
| --- | --- | --- | --- | --- |
| 纸 | 草纸 | 羊皮纸 | 至邪之笺 | 寂灭之笺 |
| 墨 | 墨水 | 血墨 | 不洁之墨 | — |
| 线 | 麻绳 | 金绳 | 龙筋 | — |

单条线的加成：**Ⅰ 0、Ⅱ +0.5%、Ⅲ +2.5%、Ⅳ +6%**。

三层叠加：

1. **全属性** = 三条线相加，四条属性（攻击力 / 生命上限 / 护甲 / 移动速度）都加这么多；
2. 每条材料线出书时各自掷一项属性，**再把自己那一份加到那一项上**；
3. 换料 / 重掷只改被替换那一条线的档位与掷中的属性，另外两条原封不动。

以 Ⅳ/Ⅲ/Ⅲ 的书为例：

| 层 | 内容 |
| --- | --- |
| 全属性 | +11%（6 + 2.5 + 2.5）加到四项上 |
| 纸线（Ⅳ，掷中攻击力） | 攻击力再 +6% → 攻击力合计 +17% |
| 墨线（Ⅲ，掷中生命上限） | 生命上限再 +2.5% → 合计 +13.5% |
| 线线（Ⅲ，掷中护甲） | 护甲再 +2.5% → 合计 +13.5% |

> 数值经过一轮压低：三条线会相加，饰品栏里每一本书也都算，按最初的「Ⅱ +1% / Ⅲ +6% / Ⅳ +10%」叠起来太高，
> 最终定为上面的 0 / 0.5% / 2.5% / 6%。

四项属性 = **攻击力、生命上限、护甲、移动速度**。三条线如果掷中同一项，那一项会叠三份。

**独立乘区**：材料加成是乘算，乘在「所有固定值加成算完之后」的总数上。所以它不会被别的模组的固定值加成冲淡，也不会和「造成伤害 +X%」这类加法混在一起。

**饰品栏里的每一本书都算**：戴四本带档位的书，就是四份相加，按属性分别累计后一起生效。

**显示方式**：物品介绍末尾是仿饰品模组的区块 ——

```
材料加成：
+11.0% 全属性（三条相加）
+6.0% 攻击力
+2.5% 生命上限
+2.5% 护甲
材料档位：纸 Ⅳ · 墨 Ⅲ · 线 Ⅲ
槽位：书
```

第一行是三条相加的总量，下面三行是每条线各自掷中的那一项（掷中同一项就会重复出现，读起来就是叠了三份）。

> 区块标题是「**材料加成：**」，和饰品栏自己那段「当装备在书籍栏：」分开读：
> 前者是这本书记录的材料档位带来的加成，后者是这件物品本身自带的属性。

怎么把档位写到书上，有三条路：

| 路径 | 说明 |
| --- | --- |
| 著书台（纸/墨/线三格 + 下半材料池 → 书） | 出书时按三格材料打档，并掷出额外属性 |
| 锻造台「换料重铸」 | 给已有书换掉某一条线，见下 |

> **书类合成表一律在著书台**，工作台不出书。


#### 锻造台：换料重铸

| 格位 | 放什么 |
| --- | --- |
| 模板（第 1 格） | 空书卷 ×1，消耗 |
| 装备（中间格） | 任意一本带档位的书 |
| 材料（第 3 格） | 纸 / 墨 / 线任意一件 |

- 放**哪条线的材料**，就换那一条线的档位（放纸换纸、放墨换墨、放线换线）。
- **只升不降**：新材料档位高于原档才改；用同档材料则是纯粹重掷随机属性。
- 每次重铸都会**只重掷被替换那一条线**的属性；另外两条线保持原样。

这把重铸走的是数据包配方，JEI 里能查到，整合包也能改。

三条设计约束：

- 没有材料档位的书（指令发的、这个功能之前写的）**加成为 0**，tooltip 也不显示那一行，不假装有；全 Ⅰ 材料的书总加成同样是 0。

- 寂灭之笺（Ⅳ）现在可达：著书台的纸格放它即可（配方里写的是「草纸」的书，换成更高档的纸照样成立）。

#### 《道德经》的著书台配方

| 格位 | 放什么 | 数量 |
| --- | --- | --- |
| 纸 | 草纸（`yanscriptures:fiber_paper`） | 2 |
| 墨 | 墨水（`yanscriptures:ink`） | 1 |
| 线 | 麻绳（`yanscriptures:hemp_rope`） | 2 |
| 材料池 | 金胡萝卜 + 金苹果 | 各 1 |

- 三种基础材料以外的东西（这里是金胡萝卜、金苹果）放在**台子下半部分的材料池**里，界面上不占格子。
- 数量是「总共要几个」：选择格放一张、池里再放一张，或者选择格直接放两张都成立。
- 高等级材料可以替换低等级的：草纸换羊皮纸/至邪之笺/寂灭之笺，墨水换血墨/不洁之墨，麻绳换金绳/龙筋，照样出书，档位按实际放进去的东西算。

- Shift 右键的整段逻辑走 `BookWritingTableEvents`（`PlayerInteractEvent.RightClickBlock`，HIGHEST），
  在那里把原版的「物品对 block 使用」DENY 掉，否则末影珍珠这类会抢先触发自己的效果；
  同时按「玩家 + 这一刻」去重，避免「放进去又被全部退回来」。

### 界面只有三个格子

材料池**不在界面里显示成槽位**：界面只有纸 / 墨 / 线三个选择格，
材料到底存了什么用右下方的文字清单列出来（滚轮翻页）。

- 三个选择格按原版容量走，**可以整叠放进去**。
- 写书时按「先扣材料池里的同种物品，池里没有才扣选择格」的顺序各扣一份；
  扣之前先确认三样都够，避免「纸扣了、墨不够」白吃一张纸。
- 材料清单靠 10 个不可见、也点不到的隐藏槽位显示出来。

### 候选配方与上下小三角

**只要纸、墨、线三格放好，成品框旁边就会出现上下两个小三角**（右上角显示「第几条 / 共几条」），
点一下换下一本书，同时把那一本还缺的下方材料列在成品名下面。
三格空着、或一本都对不上档位时，成品框显示「未选定配方」。

- 候选列表按当前三格的材料现算：**稀有及以下的书不卡档位**（草纸也能写平时要羊皮纸的书，成品强弱照旧看实际用料），
  **只有史诗书和要寂灭之笺的终局书**才要求指定档位，档位不够的那几本不会出现在候选里。
  排序按「纸档位 + 墨档位 + 线档位」从小到大（《道德经》最便宜，排第一），不看材料池够不够，
  真正写不写得成只看材料够不够，没凑齐也能先翻着看。
- 选中的那本按**配方 id** 记住（存在方块实体的 `SelectedId` 里），关界面、拆下来再放、换界面重开都还是那一本；
  候选列表重算后先按 id 找回它，找不到（比如换成低档材料后这本书不再可写）才退回第一条。
- 点箭头立刻切换（本地先动，再与服务端确认），不会因为延迟点错。
- 材料池列表底下有一行淡蓝色小字「材料齐全后，使用空书卷右键著书台获取书籍」，字号按可用宽度自动缩放（写满 168 像素、贴着右边框）。
- 左上角两行：上面是书名（按 52 像素截断成「《一千零一夜…》」），下面只在缺东西时写「还需 N 项」（红字），
  **材料齐了什么也不显示**（能点就能写，不再刷那句长提示）。具体缺哪些、各缺几个，把鼠标停在成品框上看悬浮提示。
- 「第 16 / 22 张」这类页码右对齐在界面内（`168 - 文字宽`），不会再顶出界面；材料池上方那行操作提示已删除。
- 配方需要额外材料（例如《道德经》要金胡萝卜、金苹果）时，这行只在**选中那一本**时算，切到别的书跟着变。
- 配方写的是**档位**（纸 Ⅰ~Ⅳ、墨 Ⅰ~Ⅲ、线 Ⅰ~Ⅲ）而不是具体物品，所以高等级纸能写低等级的书。
- 想加新材料只改标签（纸 / 墨 / 线三条），不用改代码。
- 写成的提示是「写成了《书名》」，不会再套一层书名号。
- **每写成一本，台面上那本《书与笔》随之消耗**：书槽清空后要重新放一本才写得下一本。
- 自查：三格放好、材料池为空时，候选条数 = 当前档位能写的本数（至少 1 条，箭头才会出现）；
  0 条说明三格里有空、或这三档凑不出一本（例如只放了一档纸却想写要三档纸的书）。

### 10.3 两段式发放：先「就绪」，再「违逆」

这是整套系统里唯一不直观的地方，也是刻意设计：

1. **条件达成时只记「就绪」状态**，不立刻给物品；
2. 后台每 20 刻扫一次就绪队列，十张残卷**额外要求**玩家戴着《圣典·戒律》且已经「违逆」过那一条诫命，才真正发放；
3. 发放成功同时记下「已发放」，发不进背包就原地掉落。

于是残卷的叙事成立：**先看见自己的罪，才拿得到那一卷**。史诗没有这层门槛，就绪即发。

就绪期间玩家会收到一行灰字提示，说明还差「违逆」这一步。

### 10.4 三条判定规则

| 规则 | 说明 |
|---|---|
| **「一场战斗」** | 造成或受到伤害都会把窗口续到 5 秒后；连续 5 秒没有交手、死亡或退出就结算。打一下就跑不累计 |
| **「首领」** | 原版末日方舟一类的固定名单，加上各模组登记的「首领」类生物；**不按血量判定**——装了很多模组后普通怪血量也会暴涨 |
