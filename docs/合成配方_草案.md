> 规则（作者 2026-11-10 定）：
> 1. 书籍类饰品一律 = **三种基础材料（纸 / 墨 / 线）** + **2~6 种其他材料**。
> 2. **史诗**书籍至少用到**一种三级材料**，其他材料也要更稀有。
> 3. 材料获取难度按**书籍强度**排列。
> 4. 空书架的获取时间点落在**中后期**。

## 六、几个说明

1. **难度递进的口径**：纸/墨/线的档位差一档，等于多一整条炼药锅产线（例如至邪之笺要凋灵玫瑰 + 邪恶精华）；其他材料按「原版常见 → 下界 → 末地/远古城市 → 诡厄/星月 Boss 掉落 → 启示录终局材料」排序。
2. **三级材料只对史诗强制**：稀有书的纸墨线最高到 Ⅱ，避免玩家为了写一本小书就跑一遍凋灵。
3. **寂灭之星 / 神灵金属锭 / 湮灭心石** 只出现在 S 与 A 段，S 段每本都要其一，作为「终局门槛」。
4. 若某些材料在整合包里被删（例如不装诡厄），把对应项换成同档位替代即可——配方表里每件都留了 4~6 个槽，删一个不影响成立。
