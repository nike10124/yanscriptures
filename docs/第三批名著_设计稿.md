## 填这份稿子时要注意的四件事

1. **id 不能改**。id 同时是贴图名（`assets/yanscriptures/textures/item/<id>.png`）、模型名、
   `data/yanscriptures/tags/items/books.json`、`data/curios/tags/items/book.json` 的条目和
   lang 键名。真要改，五处一起改。
2. **乘区规则**（2026-11-01 定）：凡「属性提高 X%」一律 `MULTIPLY_BASE`（同一乘区先相加再整体乘）；
   **独立乘区（`MULTIPLY_TOTAL`）只留给材料档位**。「造成伤害 +X%」不进属性面板，走
   `LivingHurtEvent` 自己算，不占乘区。
3. **每本只做一件能被一句话讲清的事**。优先用事件（`LivingHurtEvent` / `LivingDeathEvent` /
   `LivingHealEvent` / `PlayerTickEvent`），不要每 tick 扫背包；佩戴判定一律 `WornCache.wears`。
4. **一本书一个文件**（`XxxHandler.java`），不要往 `ClassicBooksHandler` 里塞。

## 1.《伊利亚特》 `iliad`

| 项 | 内容 |
| --- | --- |
| 分类 | 文学 |
| 贴图 | 暗红封面、交叉长矛与头盔 |
| 引语 | 「女神啊，请歌唱佩琉斯之子阿喀琉斯的愤怒。」 |
| 当前状态 | 只注册，无机制 |

**我建议的机制（草案）**

- 单挑时（周围 8 格内没有其他生物）攻击伤害 +15%，受到的伤害 -10%。
- 被两个及以上敌对生物同时锁定时，伤害 -10%（阿喀琉斯的愤怒孤注一掷，但也因此被围死）。

**撞车检查**：《百年孤独》是「身边没有同伴时更强」，和「单挑」看起来像，但那条数的是**玩家同伴**，
这条数的是**敌对生物**；如果你觉得太近，可以改成「只保留单挑增伤，去掉被围惩罚」。

**作者定稿**：

```
单挑时（周围 8 格内没有其他生物）攻击力 +15%，受到的伤害 -10%，并且你和对手都不会受到会减少生命值，降低防御力，降低移速，降低攻击力的debuff影响。
被两个及以上敌对生物同时锁定时，攻击力 -10%，但你的每一次攻击会对敌人施加随机负面效果二级（8秒），你的横扫能力扩大
```

**待定**：获取方式 / 著书台档位（纸 墨 线 + 数量）

## 2.《埃涅阿斯纪》 `aeneid`

| 项 | 内容 |
| --- | --- |
| 分类 | 文学 |
| 贴图 | 黑底金纹、冥界之火 |
| 引语 | 「我歌唱战争，也歌唱一个人。」 |
| 当前状态 | 只注册，无机制 |

**我建议的机制（草案）**

- 死亡后 30 秒内，尸体位置上方出现一束「亡者指引」光柱（只对本人可见），右键它可直接回到死亡点。
- 每名玩家每游戏日只能触发一次。

**风险**：这是「跨死亡状态」的机制，和《奥德赛》的「保留物品 + 回死亡点」功能重叠。
如果你想要两本叠加，建议把《奥德赛》的回死亡点写成「按住 Shift 右键书本」，这本写成「光柱自动指路」。

**作者定稿**：

```
非boss级的亡灵生物对你将保持中立，并且会主动攻击，攻击了你的非亡灵生物，瞬间伤害，中毒和凋零将会恢复你的生命值，瞬间治疗、生命回复将会降低你的生命，饥饿效果会回复你的饱和度，和饥饿值，饱和效果会降低你的饥饿值和饱和度
```

**待定**：获取方式 / 著书台档位

## 6.《史记》 `records_of_the_historian`

| 项 | 内容 |
| --- | --- |
| 分类 | 史书（新增分类 `HISTORY`，颜色暗青） |
| 贴图 | 黑底、青色竹简与朱红印 |
| 引语 | 「究天人之际，通古今之变。」 |
| 当前状态 | 只注册，无机制 |

**我建议的机制（草案）**

- 记录你最近一次死亡的位置与死因（存进物品 NBT）。
- 右键书本：把这条记录「说」给 16 格内的其他玩家（聊天栏提示），并给自己 10 秒的「知史」加速。
- 全服共享：同一本书记得的是**持有者**的死亡，交易给别人后记录清空。

**作者定稿**：

```
每完成一个进度，使暴击率提高0.5%，暴击伤害提高1%（都是curios里的，不是原版的），幸运值提高0.5
```
