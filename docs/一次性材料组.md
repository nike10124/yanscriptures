# 一次性最全材料组

> 目标：**凑一套材料，连续把尽可能多种不同的书各做一本**。统计依据是 `data/yanscriptures/recipes/book_writing/*.json` 的实际配方。

## 为什么不是全部 37 本

纸、墨、线各只有一个档位能放进选择格，所以一次只能覆盖「同一档位组合」里的书。全部配方只落在 6 种组合上：

| 纸 / 墨 / 线 | 本数 |
| --- | --- |
| 纸2 / 墨2 / 线2 | 15 |
| 纸1 / 墨1 / 线1 | 7 |
| 纸3 / 墨2 / 线2 | 7 |
| 纸3 / 墨3 / 线2 | 5 |
| 纸4 / 墨3 / 线3 | 2 |
| 纸4 / 墨3 / 线2 | 1 |

纸Ⅱ / 墨Ⅱ / 线Ⅱ 这一组最大（15 本）；剩下的 22 本分散在别的档位上，想一次做完必须换档。

## 如果只想「台面一次摆满、中途不补料」

著书台的材料池只有 10 格（一格一种额外材料），这时最多只能同时满足 **3 本**：

- 《埃涅阿斯纪》《孙子兵法》《罪与罚》，基础料同样是纸Ⅱ / 墨Ⅱ / 线Ⅱ，额外材料并集 9 种：大地之心、守护者之心、坟尘、骨头、暗影精粹、灵魂红宝石、皮革、暗金锭、铁锭。

想连做更多本，就把额外材料放背包、中途往台面补——台面是工作区，不是仓库。
