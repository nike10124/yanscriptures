## 填这份稿子时要注意的四件事

1. **id 不能改**。id 同时是贴图名（`assets/yanscriptures/textures/item/<id>.png`）、模型名、
   `data/yanscriptures/tags/items/books.json`、`data/curios/tags/items/book.json` 的条目和
   lang 键名。真要改，五处一起改。
2. **属性写在哪**（2026-11-07 定）：无条件的属性加减、以及像《史记》那种「随进度长大的固定数值」，
   写成物品侧的「当装备在书籍栏」，玩家在 Curios 面板里能直接看见；只有**依赖条件或时机**的
   （血量阈值、层数、单挑/围攻、光环、触发后的临时增益）才留在代码里。
3. **乘区规则**（2026-11-01 定）：凡「属性提高 X%」一律 `MULTIPLY_BASE`（同一乘区先相加再整体乘）；
   **独立乘区（`MULTIPLY_TOTAL`）只留给材料档位**。「造成伤害 +X%」不进属性面板，走事件自己算，不占乘区。
4. **每本只做一件能被一句话讲清的事**，一本书一个文件（`XxxHandler.java`），不要往 `ClassicBooksHandler` 里塞。

## 1.《纯粹理性批判》 `critique_of_pure_reason`

| 项 | 内容 |
| --- | --- |
| 分类 | 哲学 |
| 贴图 | 墨蓝封面、金色八芒星与四分格 |
| 引语 | 「有两样东西，越是反复思索，越让人心中充满敬畏：头顶的星空，与心中的道德律。」 |
| 当前状态 | 只注册，无机制 |

**我建议的机制（草案）**

- 「先验」：你对**从未伤害过你**的生物造成伤害 +15%；一旦它伤到你，这条加成对该生物失效。
- 「道德律」：你从未主动攻击过的生物（和平生物与中立生物）对你造成的伤害 -20%。

**撞车检查**：《孙子兵法》管的是「没盯上你的敌人」，这条管的是「没伤过你的敌人」，两者不重叠；
但两条都在「先手」上做文章，如果你觉得太像，可以只保留其中一条。

**作者定稿**：

```
背包内每多一种附魔，造成伤害提高0.5％，生命值提高1%，每一个格子单独计算（不同格之间的重复附魔可以计算）（附魔书不计入其中）
若背包里所有物品（格子可以为空，但总有物品格数要大于21）都有附魔效果，获得创造飞行
包括快捷栏，物品栏，装备栏

你从未主动攻击过的生物（和平生物与中立生物）对你造成的伤害 -20%。

```

**待定**：无。

## 2.《尼各马可伦理学》 `nicomachean_ethics`

| 当前状态 | 只注册，无机制 |

- 「中庸」：生命值在 **50%~80%** 之间时，攻击力 +10%、受到伤害 -5%；低于 50% 或高于 80% 都拿不到。

**撞车检查**：《君主论》按「高血/低血」两段给不同加成，这条是「中间一段」，视觉上不会打架，
但都读生命比例，如果你不想重复这个变量，可以删掉「中庸」只留「习惯」。

**作者定稿**：

```
在存在仇恨并且进行攻击时，5秒没有受到伤害，移动速度提高15%，10秒没有受到伤害，攻击力提高15%，15秒没有受到伤害，暴击率提高15%，暴击伤害提高30%，30秒没有受到伤害，造成的伤害提高50%，60秒没有受到伤害，造成的每一次攻击附加一次伤害与当前攻击相同的小范围伤害
时间长时，每一级效果都会得到保留，受到伤害或者脱战时全部清零
你攻击的目标必须要对你抱有敌意
```
