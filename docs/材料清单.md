# 可用材料清单（原版 + 已装模组）

> 统计口径：只看**物品**（方块物品如原木、矿石也记在里面），不含刷怪蛋、药水、唱片、旗帜图案。
> 「材料」是我按 id 关键词粗分的类别，**不代表只能当材料用**——`/kubejs` 或配方里任何物品 id 都能引用，
> 包括武器、盔甲、饰品。

已装的内容模组共 5 个（另有 Curios / JEI / Jade / Patchouli / 卡埃勒斯 / 月光库这类前置或库模组，本身不提供材料）。

| 模组 | 一句话 | 物品数 | 材料类 | 装备/武器/饰品 |
|---|---|---:|---:|---:|
| 星月核心（celestial_core） | 所有星月系列模组的材料基础：碎片、精华、金属锭 | 55 | 19 | 28 |
| 星月遗物（celestial_artifacts） | 饰品与核心材料，多为 BOSS / 事件掉落 | 106 | 17 | 42 |
| 神秘遗物（Enigmatic Legacy） | 以太金属、灵魂系列、七咒之戒与大量饰品 | 105 | 30 | 34 |
| 诡厄巫法（Goety） | 黑暗魔法：金属锭、灵魂、聚晶、仪式材料 | 384 | 55 | 99 |
| 诡厄巫法：启示录（Goety Revelation） | 终末系列：神灵金属、寂灭之星、环类饰品 | 74 | 12 | 30 |

## 四、几个值得标注获取方式的材料

> 下面这些是我能从 jar 内的语言文件直接确认的；**其余材料的掉落表在 jar 里看不到，请以 JEI 为准**（JEI 会把每个物品的合成与掉落都列出来）。

| 材料 | 获取方式 |
|---|---|
| `goety_revelation:quietus_star` 寂灭之星 | 击杀凋灵 **2.5%** 掉落；穿戴教主套装时 **6.66%**（取自模组自带说明） |
| `goety_revelation:apocalyptium_ingot` 神灵金属锭 | 由「黑暗金属装备 + 神灵金属锭」的锻造模板升级而来（`smithing_template.apocalyptium_upgrade`） |
| `goety:unholy_blood` 不洁之血 / `enigmaticlegacy:evil_essence` 邪恶精髓 | 我们自己的炼药锅配方在用，掉落来源请查 JEI |
| `celestial_core:*_fragment`（光明 / 子夜 / 樱花 / 宝藏 / 心之碎片） | 星月系列的事件与宝箱掉落，具体见 JEI |
| `enigmaticlegacy:etherium_ore` 以太矿石 → 以太粒 → 以太锭 | 神秘遗物的金属线，矿石生成维度请查 JEI / 模组书 |
| `goety:soul_energy` 灵魂能量、`goety:soul_jar` 灵魂罐 | 诡厄巫法的灵魂系统：击杀生物积累能量，罐子用于存储与仪式 |

## 五、在 KubeJS 里引用这些材料

```js
// 任意配方里都能直接写 id，也能写标签
ServerEvents.recipes(event => {
  // 用标签：任意原木 + 我们的纸
  event.shaped('yanscriptures:blank_page', [
    'LL',
    'PP'
  ], {
    L: '#minecraft:logs',
    P: 'yanscriptures:fiber_paper'
  })

  // 用模组材料：诡厄巫法的不洁之血
  event.shapeless('3x yanscriptures:corrupt_parchment', [
    'yanscriptures:parchment',
    'goety:unholy_blood'
  ])

  // 用装备当材料（比如把某把武器熔掉）
  event.smelting('minecraft:iron_ingot', 'goety:dark_alloy_sword').xp(0.5)
})
```

著书台的配方是数据驱动的（`yanscriptures:book_writing`），写法见 `docs/KubeJS对接.md`；`/ys book <书> <纸档> <墨档> <线档>` 可以跳过配方直接生成。
