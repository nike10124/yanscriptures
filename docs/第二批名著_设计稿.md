## 改这份稿子时要注意的三件事

1. **id 不能随手改**。id 同时是贴图文件名（`assets/yanscriptures/textures/item/<id>.png`）、
   模型名、`data/*/tags/items/books.json` 与 `data/curios/tags/items/book.json` 里的条目、
   以及 `lang` 的键名。真要改，这五处一起改。
2. **数值写进代码时的乘区规则**（2026-11-01 定）：凡是「属性提高 X%」一律 `MULTIPLY_BASE`
   （乘法乘区，多条之间相加再整体乘），**独立乘区只留给材料档位**（`MaterialBonusHandler`）。
   「造成伤害 +X%」这类不在属性面板里的，走 `LivingHurtEvent` 自己算，不占用任何乘区。
3. **每本只做一件能被一句话讲清的事**（和第一批九本一样）。机制优先用事件
   （`LivingHurtEvent` / `LivingDeathEvent` / `LivingHealEvent` / `PlayerTickEvent`），
   不要每 tick 扫背包。
