# 更新日志

## 0.1.1 — 修复（2026-11-13）

- 新增「至理之书」：作者 ID 首次进入存档时获得，使用后随机得到一本史诗名著（书会消耗）。
- 新增「启示残卷」与「真我的史诗」的获取方式：十条诫全部反转后自动获得一张启示残卷；
  已经拿到过另外四块史诗、并在**下界**打完亚波伦的尾杀后，获得「真我的史诗」。
  四块史诗改用进度记录，退出重进不再重置。
- 启示试炼中被亚波伦亲手杀死时，除补回残卷外额外给一张赎罪券
  （物资由标签 `yanscriptures:apollyon_trial_reward` 提供，没装对应模组时静默跳过）。
- 修复 `mods.toml` 中文在 Windows 下被打包成乱码（`processResources` 未指定字符集）。
- 新增 `/ys perf` 与 `/ys perf reset`，用于查看每 tick 事件耗时与每帧 HUD 耗时。

## 0.1.0 — 初版（2026-11-11）

首个公开版本。

### 内容

- **36 本名著**，按哲学、文学、科学、军事、政治、医学、工艺、心理、历史九类划分；
  每本都有独立机制，其中 14 本为「史诗」稀有度。
- **三件毕业饰品**：圣约·原典、如我所书、十诫。
- **配套系统**：著书台（纸 / 墨 / 线各四档，配方数据驱动，可用 KubeJS 增删改）、
  炼药锅配方、锻造台换料、著书笔与空白书卷、十张诫命残卷、五块史诗石板、启示残卷。
- **27 条成就**：含 14 条史诗书成就、1 条「寂灭之笺」成就与「百家争鸣」全收集挑战。

### 其它

- 中英双语（`zh_cn` / `en_us`）。
- 与 Curios、JEI、Jade 联动：JEI 收录炼药锅与著书台配方，并为每本书提供机制说明页。
- 兼容整合包常见的基础属性 / 暴击类模组，未硬编码其它模组的类名或字段。

### 依赖

- **必需**：Minecraft 1.20.1、Forge 47.x、Curios 5.14.1+
- **可选（装了内容才完整）**：Goety（诡厄巫法）、Goety: Revelation、星月遗物 / 星月核心、神秘遗物
- 只装必需项也能正常启动与游玩，只是部分史诗书的材料与圣约后的试炼内容会缺失。
